[SIZE=5][B]English Version[/B][/SIZE]
Kits without editing a single config line. Fill your inventory, run one command and the kit is ready. UltraKits shows every kit in a GUI with preview, handles cooldowns, prices and one-time kits and gives new players their starter kit automatically.

[B]⭐ Features at a glance:[/B]
[LIST]
[*]🧰 [B]In-Game Creation:[/B] Create a kit from your inventory with /createkit – enchantments and names included.
[*]👀 [B]GUI with Preview:[/B] Left-click to claim, right-click to preview every item.
[*]⏳ [B]Cooldowns & Prices:[/B] Cooldowns like 12h, prices via Vault and one-time kits.
[*]🎁 [B]First-Join Kit:[/B] New players receive their starter kit automatically.
[*]🛡️ [B]Auto Equip:[/B] Armour is put on automatically, overflow is dropped safely.
[*]⚡ [B]Command Rewards:[/B] Kits can run commands, e.g. give money or a rank.
[*]✨ [B]Clean Layout:[/B] Feedback in the action bar, only errors in the chat – the same look in every Ultra plugin.
[*]🚀 [B]Lightweight:[/B] No required dependencies; runs on Spigot, Paper and Purpur.
[/LIST]

[B]🌍 Languages:[/B] English, Deutsch, Français, Nederlands, Italiano – every player automatically gets the language of their Minecraft client. Change the default with /ultrakits language <code>.
[B]📦 Requirements:[/B] Spigot, Paper, Purpur · Minecraft 1.20.4 – 26.3 · Java 17+ · no required dependencies · Vault (optional, for kit prices)

[SPOILER=Commands & Permissions (EN)]
[LIST]
[*][B]/kit [name] [player][/B] – Claim a kit or give it to a player · [I]ultrakits.kit[/I] (default: everyone)
[*][B]/kits[/B] – Open the kit list · [I]ultrakits.kit[/I] (default: everyone)
[*][B]/createkit <name>[/B] – Create a kit from your inventory · [I]ultrakits.create[/I] (default: OP)
[*][B]/editkit <name> <items|cooldown|cost|onetime|firstjoin|icon> [value][/B] – Change items, cooldown, price, one-time, first join or icon · [I]ultrakits.edit[/I] (default: OP)
[*][B]/delkit <name>[/B] – Delete a kit · [I]ultrakits.delete[/I] (default: OP)
[*][B]/ultrakits <help|reload|version|language>[/B] – Help, reload, version and language · [I]ultrakits.admin[/I] (default: OP)
[/LIST]
[B]More permissions:[/B]
[LIST]
[*][I]ultrakits.give[/I] – Give kits to other players (default: OP)
[*][I]ultrakits.bypass.cooldown[/I] – Skip cooldowns (default: OP)
[*][I]ultrakits.*[/I] – All permissions of the plugin (default: OP)
[*][I]ultrakits.kit.<name>[/I] – Claim the kit <name>
[/LIST]
[/SPOILER]
[SPOILER=View Full Configuration (EN)]
[CODE]
# Default language: en, de, fr, nl, it
# Change it here or in-game with /ultrakits language <code>.
language: en

# true: every player gets the plugin in the language of their Minecraft client,
# as long as it is one of the five above. Everyone else gets "language".
use-client-language: true

# Colours used in every message and GUI.
theme:
  primary: "#8B5CF6"
  accent: "#22D3EE"
  muted: "#94A3B8"
  separator: "#64748B"
  error: "#F87171"
  error-text: "#FCA5A5"

sounds:
  enabled: true
  success: {key: "entity.experience_orb.pickup", pitch: 1.4}
  error: {key: "block.note_block.bass", pitch: 0.6}
  tick: {key: "block.note_block.hat", pitch: 1.0}
  teleport: {key: "entity.enderman.teleport", pitch: 1.0}
  click: {key: "ui.button.click", pitch: 1.2}

# Cooldown of new kits in seconds (change per kit with /editkit <kit> cooldown 12h).
default-cooldown: 86400

# Armour in a kit is put on automatically if the slot is empty.
auto-equip: true

# true: kits a player has no permission for are not shown in /kits.
hide-locked-kits: false

# Kits are stored in kits.yml. Besides the in-game editor you can add console
# commands there that run when the kit is claimed, e.g.
#   commands: ["eco give %player% 100"]
# and set "permission: false" to make a kit available without ultrakits.kit.<name>.
[/CODE]
[/SPOILER]

[*]⚡ [B]Befehls-Belohnungen:[/B] Kits können Befehle ausführen, z. B. Geld oder einen Rang vergeben.
[*]✨ [B]Sauberes Layout:[/B] Rückmeldungen in der Actionbar, nur Fehler im Chat – gleicher Look in jedem Ultra-Plugin.
[*]🚀 [B]Leichtgewichtig:[/B] Keine Pflicht-Abhängigkeiten; läuft auf Spigot, Paper und Purpur.
[/LIST]

[B]🌍 Sprachen:[/B] English, Deutsch, Français, Nederlands, Italiano – jeder Spieler bekommt automatisch die Sprache seines Minecraft-Clients. Standardsprache ändern mit /ultrakits language <code>.
