# ✦ UltraVanish [1.20.4+] ✦

*Unsichtbar. Lautlos. Sicher.*

──────── ✦ ────────

---

## English Version

Real invisibility for your staff team. UltraVanish hides staff from the world, the tab list and the server list, opens chests silently and blocks every interaction that could give them away. A permanent action-bar status always shows that you are vanished.

### ⭐ Features at a glance:

- 👻 **Completely Hidden:** Invisible in the world, tab list and player count – no join or quit message.
- 📊 **Action-Bar Status:** Always see how many players cannot see you.
- 🤫 **Silent Chests:** Open containers without animation or sound.
- 🚷 **No Interactions:** No mob targeting, no item pickup, no pressure plates.
- 🎚️ **Vanish Levels:** Higher ranks see lower ones (ultravanish.level.<number>).
- 🎭 **Fake Join & Quit:** Fake messages when vanishing or reappearing – automatic or by command.
- ✨ **Clean Layout:** Feedback in the action bar, only errors in the chat – the same look in every Ultra plugin.
- 🚀 **Lightweight:** No required dependencies; runs on Spigot, Paper and Purpur.

**🌍 Languages:** English, Deutsch, Français, Nederlands, Italiano – every player automatically gets the language of their Minecraft client. Change the default with /ultravanish language <code>.

**📦 Requirements:** Spigot, Paper, Purpur · Minecraft 1.20.4 – 26.3 · Java 17+ · no required dependencies

<details><summary>Commands & Permissions (EN)</summary>

- `/vanish [player]` (aliases: `/v`) – Turn vanish on or off · `ultravanish.vanish` (default: OP)
- `/vanishlist` – List vanished players · `ultravanish.list` (default: OP)
- `/fakejoin` – Send a fake join message · `ultravanish.fake` (default: OP)
- `/fakequit` – Send a fake quit message · `ultravanish.fake` (default: OP)
- `/ultravanish <help|reload|version|language>` – Help, reload, version and language · `ultravanish.admin` (default: OP)

**More permissions:**

- `ultravanish.vanish.others` – Vanish other players (default: OP)
- `ultravanish.see` – See vanished players (same or lower level) (default: OP)
- `ultravanish.*` – All permissions of the plugin (default: OP)
- `ultravanish.level.<number>` – Vanish level

</details>

<details><summary>View Full Configuration (EN)</summary>

```yaml
# Default language: en, de, fr, nl, it
# Change it here or in-game with /ultravanish language <code>.
language: en

# true: every player gets the plugin in the language of their Minecraft client,
# as long as it is one of the five above. Everyone else gets "language".
use-client-language: true

# Colours used in every message and GUI.
theme:
  primary: "#8B5CF6"
  accent: "#22D3EE"
  muted: "#94A3B8"
  separator: "#64748B"
  error: "#F87171"
  error-text: "#FCA5A5"

sounds:
  enabled: true
  success: {key: "entity.experience_orb.pickup", pitch: 1.4}
  error: {key: "block.note_block.bass", pitch: 0.6}
  tick: {key: "block.note_block.hat", pitch: 1.0}
  teleport: {key: "entity.enderman.teleport", pitch: 1.0}
  click: {key: "ui.button.click", pitch: 1.2}

# Staff with ultravanish.vanish is vanished automatically when joining.
vanish-on-join: false

# Remove vanished players from the player count and list in the server list.
hide-from-player-count: true

# Send a fake quit/join message when vanishing/reappearing.
fake-messages-on-toggle: true

# Right-clicking a container while vanished opens it without animation and sound.
# Sneak while clicking to open it normally.
silent-chests: true

allow-item-pickup: false

# Managed by the plugin: players who are vanished, so it survives restarts.
vanished: []
```

</details>

## Deutsche Version

Echte Unsichtbarkeit für dein Team. UltraVanish versteckt Teammitglieder in der Welt, der Tabliste und der Serverliste, öffnet Kisten lautlos und verhindert jede Interaktion, die sie verraten könnte. Ein dauerhafter Status in der Actionbar zeigt immer, dass du unsichtbar bist.

### ⚙️ Deine Vorteile:

- 👻 **Komplett versteckt:** Unsichtbar in Welt, Tabliste und Spielerzahl – keine Join- oder Quit-Nachricht.
- 📊 **Actionbar-Status:** Immer sehen, für wie viele Spieler du unsichtbar bist.
- 🤫 **Lautlose Kisten:** Behälter ohne Animation und Geräusch öffnen.
- 🚷 **Keine Interaktionen:** Kein Mob-Targeting, kein Item-Aufheben, keine Druckplatten.
- 🎚️ **Vanish-Level:** Höhere Ränge sehen niedrigere (ultravanish.level.<zahl>).
- 🎭 **Fake-Join & Quit:** Fake-Nachrichten beim Verschwinden oder Auftauchen – automatisch oder per Befehl.
- ✨ **Sauberes Layout:** Rückmeldungen in der Actionbar, nur Fehler im Chat – gleicher Look in jedem Ultra-Plugin.
- 🚀 **Leichtgewichtig:** Keine Pflicht-Abhängigkeiten; läuft auf Spigot, Paper und Purpur.

**🌍 Sprachen:** English, Deutsch, Français, Nederlands, Italiano – jeder Spieler bekommt automatisch die Sprache seines Minecraft-Clients. Standardsprache ändern mit /ultravanish language <code>.

**📦 Voraussetzungen:** Spigot, Paper, Purpur · Minecraft 1.20.4 – 26.3 · Java 17+ · keine Pflicht-Abhängigkeiten
