## English Version

A clean, good-looking chat without extra plugins. UltraChat brings rank formats with gradients and hover text, chat channels, private messages and a filter against spam, caps and advertising. Mentions and [item] make the chat feel modern.

### ⭐ Features at a glance:

- 🎨 **Rank Formats:** MiniMessage formats with gradients and hover text; shows prefix and suffix from UltraRanks or any Vault rank plugin.
- 📢 **Channels:** Global, local (radius) and staff channels plus your own – switch with /channel.
- ✉️ **Private Messages:** /msg and /r with the usual aliases, /socialspy for staff.
- 🧹 **Smart Filter:** Blocks advertising, spam and blocked words; caps are lowered automatically.
- 🔔 **Mentions & [item]:** @Name notifies the player, [item] shows your item with tooltip.
- 🛠️ **Moderation:** /chatclear, /mutechat and /slowmode for your team.
- ✨ **Clean Layout:** Feedback in the action bar, only errors in the chat – the same look in every Ultra plugin.
- 🚀 **Lightweight:** No required dependencies; runs on Spigot, Paper and Purpur.

**🌍 Languages:** English, Deutsch, Français, Nederlands, Italiano – every player automatically gets the language of their Minecraft client. Change the default with /ultrachat language <code>.

**📦 Requirements:** Spigot, Paper, Purpur · Minecraft 1.20.4 – 26.3 · Java 17+ · no required dependencies

<details><summary>Commands & Permissions (EN)</summary>

- `/msg <player> <message>` (aliases: `/tell`, `/w`, `/whisper`, `/pm`) – Send a private message · `ultrachat.msg` (default: everyone)
- `/r <message>` (aliases: `/reply`) – Reply to the last private message · `ultrachat.msg` (default: everyone)
- `/channel [name]` (aliases: `/ch`) – Show or switch your chat channel · `ultrachat.channel` (default: everyone)
- `/chatclear` (aliases: `/cc`) – Clear the chat for everyone · `ultrachat.clear` (default: OP)
- `/mutechat` – Lock or unlock the chat · `ultrachat.mutechat` (default: OP)
- `/slowmode <seconds>` – Seconds between two messages (0 = off) · `ultrachat.slowmode` (default: OP)
- `/socialspy` – Read private messages of others · `ultrachat.socialspy` (default: OP)
- `/ultrachat <help|reload|version|language>` – Help, reload, version and language · `ultrachat.admin` (default: OP)

**More permissions:**

- `ultrachat.channel.staff` – Read and write in the staff channel (default: OP)
- `ultrachat.color` – Use &-colour codes in chat (default: OP)
- `ultrachat.bypass.filter` – Bypass the chat filter (default: OP)
- `ultrachat.bypass.slowmode` – Bypass the slow mode (default: OP)
- `ultrachat.bypass.mutechat` – Write while the chat is locked (default: OP)
- `ultrachat.bypass.clear` – Keep your chat on /chatclear (default: OP)
- `ultrachat.*` – All permissions of the plugin (default: OP)
- `ultrachat.format.<name>` – Use the chat format <name>

</details>

<details><summary>View Full Configuration (EN)</summary>

```yaml
# Default language: en, de, fr, nl, it
# Change it here or in-game with /ultrachat language <code>.
language: en

# true: every player gets the plugin in the language of their Minecraft client,
# as long as it is one of the five above. Everyone else gets "language".
use-client-language: true

# Colours used in every message and GUI.
theme:
  primary: "#8B5CF6"
  accent: "#22D3EE"
  muted: "#94A3B8"
  separator: "#64748B"
  error: "#F87171"
  error-text: "#FCA5A5"

sounds:
  enabled: true
  success: {key: "entity.experience_orb.pickup", pitch: 1.4}
  error: {key: "block.note_block.bass", pitch: 0.6}
  tick: {key: "block.note_block.hat", pitch: 1.0}
  teleport: {key: "entity.enderman.teleport", pitch: 1.0}
  click: {key: "ui.button.click", pitch: 1.2}

# Chat formats in MiniMessage. A player gets the first format (top to bottom) they have
# the permission ultrachat.format.<name> for, otherwise "default".
# Placeholders: <player> display name, <name> account name, <world>, <message>,
#               <prefix> <suffix> <rank> from UltraRanks (or any rank plugin through Vault)
# Hover and click work as usual, e.g. <hover:show_text:'World: <world>'><player></hover>
formats:
  default: "<prefix><hover:show_text:'<muted>World: <white><world>'><white><name></white></hover><suffix> <sep>»</sep> <white><message>"

# Channels. Players switch with /channel <name>.
# prefix: shown before the format, radius: blocks (0 = everywhere), permission: needed to join and read
channels:
  global:
    prefix: ""
  local:
    prefix: "<muted>[L]</muted> "
    radius: 100
  staff:
    prefix: "<accent>[Staff]</accent> "
    permission: ultrachat.channel.staff
default-channel: global

# Seconds between two messages of one player. 0 = off. Also set with /slowmode.
slowmode: 0

# "@Name" highlights the name and notifies the player.
mentions: true
# "[item]" in a message shows the item in the sender's hand.
show-item: true

filter:
  words:
    blocked: []
    replacement: "***"
  caps:
    enabled: true
    min-length: 8
    # Messages with more capital letters than this are written in lower case.
    max-percent: 60
  spam:
    enabled: true
    # The same message cannot be sent again within this time.
    repeat-seconds: 30
  advertising:
    enabled: true
    # Domains that may be posted, e.g. your own.
    allowed: []
```

</details>

## Deutsche Version

Ein sauberer, schöner Chat ohne Zusatz-Plugins. UltraChat bringt Rang-Formate mit Farbverläufen und Hover-Texten, Chat-Kanäle, Privatnachrichten und einen Filter gegen Spam, Caps und Werbung. Erwähnungen und [item] machen den Chat modern.

### ⚙️ Deine Vorteile:

- 🎨 **Rang-Formate:** MiniMessage-Formate mit Farbverläufen und Hover-Texten; zeigt Prefix und Suffix aus UltraRanks oder jedem Vault-Rang-Plugin.
- 📢 **Kanäle:** Global, Lokal (Radius) und Team-Kanal plus eigene – wechseln mit /channel.
- ✉️ **Privatnachrichten:** /msg und /r mit den üblichen Aliasen, /socialspy fürs Team.
- 🧹 **Smarter Filter:** Blockiert Werbung, Spam und gesperrte Wörter; Caps werden automatisch klein geschrieben.
- 🔔 **Erwähnungen & [item]:** @Name benachrichtigt den Spieler, [item] zeigt dein Item mit Tooltip.
- 🛠️ **Moderation:** /chatclear, /mutechat und /slowmode für dein Team.
- ✨ **Sauberes Layout:** Rückmeldungen in der Actionbar, nur Fehler im Chat – gleicher Look in jedem Ultra-Plugin.
- 🚀 **Leichtgewichtig:** Keine Pflicht-Abhängigkeiten; läuft auf Spigot, Paper und Purpur.

**🌍 Sprachen:** English, Deutsch, Français, Nederlands, Italiano – jeder Spieler bekommt automatisch die Sprache seines Minecraft-Clients. Standardsprache ändern mit /ultrachat language <code>.

**📦 Voraussetzungen:** Spigot, Paper, Purpur · Minecraft 1.20.4 – 26.3 · Java 17+ · keine Pflicht-Abhängigkeiten
