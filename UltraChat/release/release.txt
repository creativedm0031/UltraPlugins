[SIZE=5][B]English Version[/B][/SIZE]
A clean, good-looking chat without extra plugins. UltraChat brings rank formats with gradients and hover text, chat channels, private messages and a filter against spam, caps and advertising. Mentions and [item] make the chat feel modern.

[B]⭐ Features at a glance:[/B]
[LIST]
[*]🎨 [B]Rank Formats:[/B] MiniMessage formats with gradients and hover text; shows prefix and suffix from UltraRanks or any Vault rank plugin.
[*]📢 [B]Channels:[/B] Global, local (radius) and staff channels plus your own – switch with /channel.
[*]✉️ [B]Private Messages:[/B] /msg and /r with the usual aliases, /socialspy for staff.
[*]🧹 [B]Smart Filter:[/B] Blocks advertising, spam and blocked words; caps are lowered automatically.
[*]🔔 [B]Mentions & [item]:[/B] @Name notifies the player, [item] shows your item with tooltip.
[*]🛠️ [B]Moderation:[/B] /chatclear, /mutechat and /slowmode for your team.
[*]✨ [B]Clean Layout:[/B] Feedback in the action bar, only errors in the chat – the same look in every Ultra plugin.
[*]🚀 [B]Lightweight:[/B] No required dependencies; runs on Spigot, Paper and Purpur.
[/LIST]

[B]🌍 Languages:[/B] English, Deutsch, Français, Nederlands, Italiano – every player automatically gets the language of their Minecraft client. Change the default with /ultrachat language <code>.
[B]📦 Requirements:[/B] Spigot, Paper, Purpur · Minecraft 1.20.4 – 26.3 · Java 17+ · no required dependencies

[SPOILER=Commands & Permissions (EN)]
[LIST]
[*][B]/msg <player> <message>[/B] (aliases: /tell, /w, /whisper, /pm) – Send a private message · [I]ultrachat.msg[/I] (default: everyone)
[*][B]/r <message>[/B] (aliases: /reply) – Reply to the last private message · [I]ultrachat.msg[/I] (default: everyone)
[*][B]/channel [name][/B] (aliases: /ch) – Show or switch your chat channel · [I]ultrachat.channel[/I] (default: everyone)
[*][B]/chatclear[/B] (aliases: /cc) – Clear the chat for everyone · [I]ultrachat.clear[/I] (default: OP)
[*][B]/mutechat[/B] – Lock or unlock the chat · [I]ultrachat.mutechat[/I] (default: OP)
[*][B]/slowmode <seconds>[/B] – Seconds between two messages (0 = off) · [I]ultrachat.slowmode[/I] (default: OP)
[*][B]/socialspy[/B] – Read private messages of others · [I]ultrachat.socialspy[/I] (default: OP)
[*][B]/ultrachat <help|reload|version|language>[/B] – Help, reload, version and language · [I]ultrachat.admin[/I] (default: OP)
[/LIST]
[B]More permissions:[/B]
[LIST]
[*][I]ultrachat.channel.staff[/I] – Read and write in the staff channel (default: OP)
[*][I]ultrachat.color[/I] – Use &-colour codes in chat (default: OP)
[*][I]ultrachat.bypass.filter[/I] – Bypass the chat filter (default: OP)
[*][I]ultrachat.bypass.slowmode[/I] – Bypass the slow mode (default: OP)
[*][I]ultrachat.bypass.mutechat[/I] – Write while the chat is locked (default: OP)
[*][I]ultrachat.bypass.clear[/I] – Keep your chat on /chatclear (default: OP)
[*][I]ultrachat.*[/I] – All permissions of the plugin (default: OP)
[*][I]ultrachat.format.<name>[/I] – Use the chat format <name>
[/LIST]
[/SPOILER]
[SPOILER=View Full Configuration (EN)]
[CODE]
# Default language: en, de, fr, nl, it
# Change it here or in-game with /ultrachat language <code>.
language: en

# true: every player gets the plugin in the language of their Minecraft client,
# as long as it is one of the five above. Everyone else gets "language".
use-client-language: true

# Colours used in every message and GUI.
theme:
  primary: "#8B5CF6"
  accent: "#22D3EE"
  muted: "#94A3B8"
  separator: "#64748B"
  error: "#F87171"
  error-text: "#FCA5A5"

sounds:
  enabled: true
  success: {key: "entity.experience_orb.pickup", pitch: 1.4}
  error: {key: "block.note_block.bass", pitch: 0.6}
  tick: {key: "block.note_block.hat", pitch: 1.0}
  teleport: {key: "entity.enderman.teleport", pitch: 1.0}
  click: {key: "ui.button.click", pitch: 1.2}

# Chat formats in MiniMessage. A player gets the first format (top to bottom) they have
# the permission ultrachat.format.<name> for, otherwise "default".
# Placeholders: <player> display name, <name> account name, <world>, <message>,
#               <prefix> <suffix> <rank> from UltraRanks (or any rank plugin through Vault)
# Hover and click work as usual, e.g. <hover:show_text:'World: <world>'><player></hover>
formats:
  default: "<prefix><hover:show_text:'<muted>World: <white><world>'><white><name></white></hover><suffix> <sep>»</sep> <white><message>"

# Channels. Players switch with /channel <name>.
# prefix: shown before the format, radius: blocks (0 = everywhere), permission: needed to join and read
channels:
  global:
    prefix: ""
  local:
    prefix: "<muted>[L]</muted> "
    radius: 100
  staff:
    prefix: "<accent>[Staff]</accent> "
    permission: ultrachat.channel.staff
default-channel: global

# Seconds between two messages of one player. 0 = off. Also set with /slowmode.
slowmode: 0

# "@Name" highlights the name and notifies the player.
mentions: true
# "[item]" in a message shows the item in the sender's hand.
show-item: true

filter:
  words:
    blocked: []
    replacement: "***"
  caps:
    enabled: true
    min-length: 8
    # Messages with more capital letters than this are written in lower case.
    max-percent: 60
  spam:
    enabled: true
    # The same message cannot be sent again within this time.
    repeat-seconds: 30
  advertising:
    enabled: true
    # Domains that may be posted, e.g. your own.
    allowed: []
[/CODE]
