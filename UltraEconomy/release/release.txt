[SIZE=5][B]English Version[/B][/SIZE]
The economy base for your server. UltraEconomy registers itself in Vault, supports as many currencies as you like and records every booking in a transaction log. Players get /pay with confirmation and a baltop GUI, admins get full control.

[B]⭐ Features at a glance:[/B]
[LIST]
[*]🔌 [B]Vault Provider:[/B] Works instantly with every shop, job or rank plugin that supports Vault.
[*]💎 [B]Multiple Currencies:[/B] Coins, gems or anything else – each with symbol, decimals and start balance.
[*]🤝 [B]/pay with Confirmation:[/B] Large payments need a click to confirm; a minimum amount stops spam.
[*]🏆 [B]Baltop GUI:[/B] The richest players with their heads – switchable between currencies.
[*]⚙️ [B]Admin Commands:[/B] /eco give, take and set for any player and currency.
[*]🧾 [B]Transaction Log:[/B] Every booking is logged and viewable in-game per player.
[*]✨ [B]Clean Layout:[/B] Feedback in the action bar, only errors in the chat – the same look in every Ultra plugin.
[*]🚀 [B]Lightweight:[/B] No required dependencies; runs on Spigot, Paper and Purpur.
[/LIST]

[B]🌍 Languages:[/B] English, Deutsch, Français, Nederlands, Italiano – every player automatically gets the language of their Minecraft client. Change the default with /ultraeconomy language <code>.
[B]📦 Requirements:[/B] Spigot, Paper, Purpur · Minecraft 1.20.4 – 26.3 · Java 17+ · no required dependencies · Vault (optional, to provide the economy to other plugins)

[SPOILER=Commands & Permissions (EN)]
[LIST]
[*][B]/balance [player][/B] (aliases: /bal, /money) – Show your balance · [I]ultraeconomy.balance[/I] (default: everyone)
[*][B]/pay <player> <amount> [currency][/B] – Send money to a player · [I]ultraeconomy.pay[/I] (default: everyone)
[*][B]/baltop[/B] – Open the leaderboard · [I]ultraeconomy.baltop[/I] (default: everyone)
[*][B]/eco <give|take|set> <player> <amount> [currency][/B] – Give, take or set balances · [I]ultraeconomy.eco[/I] (default: OP)
[*][B]/ultraeconomy <help|reload|version|language|log>[/B] – Help, reload, version, language and transaction log · [I]ultraeconomy.admin[/I] (default: OP)
[/LIST]
[B]More permissions:[/B]
[LIST]
[*][I]ultraeconomy.balance.others[/I] – See other players' balances (default: OP)
[*][I]ultraeconomy.log[/I] – View the transaction log (default: OP)
[*][I]ultraeconomy.*[/I] – All permissions of the plugin (default: OP)
[/LIST]
[/SPOILER]
[SPOILER=View Full Configuration (EN)]
[CODE]
# Default language: en, de, fr, nl, it
# Change it here or in-game with /ultraeconomy language <code>.
language: en

# true: every player gets the plugin in the language of their Minecraft client,
# as long as it is one of the five above. Everyone else gets "language".
use-client-language: true

# Colours used in every message and GUI.
theme:
  primary: "#8B5CF6"
  accent: "#22D3EE"
  muted: "#94A3B8"
  separator: "#64748B"
  error: "#F87171"
  error-text: "#FCA5A5"

sounds:
  enabled: true
  success: {key: "entity.experience_orb.pickup", pitch: 1.4}
  error: {key: "block.note_block.bass", pitch: 0.6}
  tick: {key: "block.note_block.hat", pitch: 1.0}
  teleport: {key: "entity.enderman.teleport", pitch: 1.0}
  click: {key: "ui.button.click", pitch: 1.2}

# Currencies. The first one is the main currency: Vault and other plugins use it,
# and it is used when a command names no currency.
# symbol-before: true = "$100", false = "100 Gems"   start: balance of new players
currencies:
  coins:
    symbol: "$"
    symbol-before: true
    decimals: 2
    start: 100
  gems:
    symbol: " Gems"
    symbol-before: false
    decimals: 0
    start: 0

pay:
  # Smallest amount that can be sent.
  minimum: 1
  # Payments from this amount on have to be confirmed. 0 = never.
  confirm-above: 10000

# Number of players in /baltop.
baltop-size: 56
[/CODE]
[/SPOILER]

[*]🤝 [B]/pay mit Bestätigung:[/B] Große Überweisungen brauchen einen Bestätigungs-Klick; ein Mindestbetrag verhindert Spam.
[*]🏆 [B]Baltop-GUI:[/B] Die reichsten Spieler mit Köpfen – umschaltbar zwischen Währungen.
[*]⚙️ [B]Admin-Befehle:[/B] /eco give, take und set für jeden Spieler und jede Währung.
[*]🧾 [B]Transaktions-Log:[/B] Jede Buchung wird protokolliert und ist pro Spieler im Spiel einsehbar.
[*]✨ [B]Sauberes Layout:[/B] Rückmeldungen in der Actionbar, nur Fehler im Chat – gleicher Look in jedem Ultra-Plugin.
[*]🚀 [B]Leichtgewichtig:[/B] Keine Pflicht-Abhängigkeiten; läuft auf Spigot, Paper und Purpur.
[/LIST]

[B]🌍 Sprachen:[/B] English, Deutsch, Français, Nederlands, Italiano – jeder Spieler bekommt automatisch die Sprache seines Minecraft-Clients. Standardsprache ändern mit /ultraeconomy language <code>.
