## English Version

The economy base for your server. UltraEconomy registers itself in Vault, supports as many currencies as you like and records every booking in a transaction log. Players get /pay with confirmation and a baltop GUI, admins get full control.

### ⭐ Features at a glance:

- 🔌 **Vault Provider:** Works instantly with every shop, job or rank plugin that supports Vault.
- 💎 **Multiple Currencies:** Coins, gems or anything else – each with symbol, decimals and start balance.
- 🤝 **/pay with Confirmation:** Large payments need a click to confirm; a minimum amount stops spam.
- 🏆 **Baltop GUI:** The richest players with their heads – switchable between currencies.
- ⚙️ **Admin Commands:** /eco give, take and set for any player and currency.
- 🧾 **Transaction Log:** Every booking is logged and viewable in-game per player.
- ✨ **Clean Layout:** Feedback in the action bar, only errors in the chat – the same look in every Ultra plugin.
- 🚀 **Lightweight:** No required dependencies; runs on Spigot, Paper and Purpur.

**🌍 Languages:** English, Deutsch, Français, Nederlands, Italiano – every player automatically gets the language of their Minecraft client. Change the default with /ultraeconomy language <code>.

**📦 Requirements:** Spigot, Paper, Purpur · Minecraft 1.20.4 – 26.3 · Java 17+ · no required dependencies · Vault (optional, to provide the economy to other plugins)

<details><summary>Commands & Permissions (EN)</summary>

- `/balance [player]` (aliases: `/bal`, `/money`) – Show your balance · `ultraeconomy.balance` (default: everyone)
- `/pay <player> <amount> [currency]` – Send money to a player · `ultraeconomy.pay` (default: everyone)
- `/baltop` – Open the leaderboard · `ultraeconomy.baltop` (default: everyone)
- `/eco <give|take|set> <player> <amount> [currency]` – Give, take or set balances · `ultraeconomy.eco` (default: OP)
- `/ultraeconomy <help|reload|version|language|log>` – Help, reload, version, language and transaction log · `ultraeconomy.admin` (default: OP)

**More permissions:**

- `ultraeconomy.balance.others` – See other players' balances (default: OP)
- `ultraeconomy.log` – View the transaction log (default: OP)
- `ultraeconomy.*` – All permissions of the plugin (default: OP)

</details>

<details><summary>View Full Configuration (EN)</summary>

```yaml
# Default language: en, de, fr, nl, it
# Change it here or in-game with /ultraeconomy language <code>.
language: en

# true: every player gets the plugin in the language of their Minecraft client,
# as long as it is one of the five above. Everyone else gets "language".
use-client-language: true

# Colours used in every message and GUI.
theme:
  primary: "#8B5CF6"
  accent: "#22D3EE"
  muted: "#94A3B8"
  separator: "#64748B"
  error: "#F87171"
  error-text: "#FCA5A5"

sounds:
  enabled: true
  success: {key: "entity.experience_orb.pickup", pitch: 1.4}
  error: {key: "block.note_block.bass", pitch: 0.6}
  tick: {key: "block.note_block.hat", pitch: 1.0}
  teleport: {key: "entity.enderman.teleport", pitch: 1.0}
  click: {key: "ui.button.click", pitch: 1.2}

# Currencies. The first one is the main currency: Vault and other plugins use it,
# and it is used when a command names no currency.
# symbol-before: true = "$100", false = "100 Gems"   start: balance of new players
currencies:
  coins:
    symbol: "$"
    symbol-before: true
    decimals: 2
    start: 100
  gems:
    symbol: " Gems"
    symbol-before: false
    decimals: 0
    start: 0

pay:
  # Smallest amount that can be sent.
  minimum: 1
  # Payments from this amount on have to be confirmed. 0 = never.
  confirm-above: 10000

# Number of players in /baltop.
baltop-size: 56
```

</details>

## Deutsche Version

Die Wirtschafts-Basis für deinen Server. UltraEconomy meldet sich bei Vault an, unterstützt beliebig viele Währungen und protokolliert jede Buchung. Spieler bekommen /pay mit Bestätigung und ein Baltop-GUI, Admins die volle Kontrolle.

### ⚙️ Deine Vorteile:

- 🔌 **Vault-Provider:** Funktioniert sofort mit jedem Shop-, Job- oder Rang-Plugin mit Vault-Support.
- 💎 **Mehrere Währungen:** Coins, Gems oder alles andere – jeweils mit Symbol, Nachkommastellen und Startguthaben.
- 🤝 **/pay mit Bestätigung:** Große Überweisungen brauchen einen Bestätigungs-Klick; ein Mindestbetrag verhindert Spam.
- 🏆 **Baltop-GUI:** Die reichsten Spieler mit Köpfen – umschaltbar zwischen Währungen.
- ⚙️ **Admin-Befehle:** /eco give, take und set für jeden Spieler und jede Währung.
- 🧾 **Transaktions-Log:** Jede Buchung wird protokolliert und ist pro Spieler im Spiel einsehbar.
- ✨ **Sauberes Layout:** Rückmeldungen in der Actionbar, nur Fehler im Chat – gleicher Look in jedem Ultra-Plugin.
- 🚀 **Leichtgewichtig:** Keine Pflicht-Abhängigkeiten; läuft auf Spigot, Paper und Purpur.

**🌍 Sprachen:** English, Deutsch, Français, Nederlands, Italiano – jeder Spieler bekommt automatisch die Sprache seines Minecraft-Clients. Standardsprache ändern mit /ultraeconomy language <code>.

**📦 Voraussetzungen:** Spigot, Paper, Purpur · Minecraft 1.20.4 – 26.3 · Java 17+ · keine Pflicht-Abhängigkeiten · Vault (optional, um die Economy anderen Plugins bereitzustellen)

<details><summary>Befehle & Rechte (DE)</summary>

- `/balance [player]` (Aliase: `/bal`, `/money`) – Deinen Kontostand anzeigen · `ultraeconomy.balance` (Standard: alle)
- `/pay <player> <amount> [currency]` – Einem Spieler Geld senden · `ultraeconomy.pay` (Standard: alle)
- `/baltop` – Die Rangliste öffnen · `ultraeconomy.baltop` (Standard: alle)
- `/eco <give|take|set> <player> <amount> [currency]` – Kontostände geben, abziehen oder setzen · `ultraeconomy.eco` (Standard: OP)
- `/ultraeconomy <help|reload|version|language|log>` – Hilfe, Reload, Version, Sprache und Transaktions-Log · `ultraeconomy.admin` (Standard: OP)

**Weitere Rechte:**

- `ultraeconomy.balance.others` – Kontostand anderer sehen (Standard: OP)
- `ultraeconomy.log` – Transaktions-Log einsehen (Standard: OP)
- `ultraeconomy.*` – Alle Rechte des Plugins (Standard: OP)

</details>
